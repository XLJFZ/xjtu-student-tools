工具

以下项目各自独立维护、独立发布，版本号和更新节奏互不影响。

  • 课程表同步

    开发中

    将 eHall 课程表转换为 ICS 日历，方便同步到手机、电脑和系统日历。

    • eHall
    • ICS
    • Calendar
    • 跨平台
    项目介绍

    学校课表通常只能在教务系统中查看，不方便和日常日历、提醒事项放在一起管理。 这个工具的目标是把个人课表导出为标准 iCalendar（.ics）文件， 再导入 Apple Calendar、Google Calendar、Outlook 等日历应用。

    计划中的处理包括：解析课程名称、教师、地点、星期、节次与周次， 正确处理单双周和非连续周，尽量减少重复事件与错误时间， 并在课表发生变化后支持增量更新。

    项目处于早期开发阶段，仓库目前只有项目说明，尚无可用版本或 release。

    GitHub 仓库↗（xjtu-timetable-calendar，在新标签页打开） 尚无可用版本

  • 思源学堂工具

    可用

    下载思源学堂课程资源与课程回放，并提供更可靠的资源管理和下载流程。

    • 课程资源
    • 课程回放
    • 下载
    • 开源
    项目介绍

    思源学堂的部分课程附件由网页前端动态加载，直接保存网页并不容易完整保存课件、 作业与录像。这个工具把当前账号有权访问的课程资源统一整理到本地， 并按课件、作业、录像等类型归类。

    它只访问当前登录账号本身就有权访问的课程与资源，不绕过统一身份认证， 也不改变服务器对课程资源的权限判断。使用方式与安全说明请以该仓库文档为准。

关于

XJTU Student Tools 是若干独立学生工具的统一入口。

  • 独立维护每个工具单独开发，互不依赖。
  • 独立发布各自拥有仓库与 release，可以单独升级或停止维护。
  • 独立版本管理版本号互不影响，不使用统一的 monorepo 版本。
  • 认证信息不经手门户本站不接收、不存储、不处理账号密码、Cookie、Token 或统一身份认证凭据。

本站只是一层导航与文档入口——它不复制子项目的源码，也不代替子项目的说明文档。 使用具体工具时，请以对应仓库的文档和安全须知为准。

安全与隐私

  • 本站本身不要求输入西安交通大学账号或密码。
  • 不要向任何公开 Issue、日志、截图或讨论中提交 Cookie、Token、Session 等认证信息。
  • 使用各子项目时，请先阅读对应项目的安全说明与使用范围。
  • 所有工具都应尽量在用户本地处理认证信息与数据，凭证不应上传到第三方服务。

免责声明
