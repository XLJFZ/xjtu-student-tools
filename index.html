    项目介绍

    学校课表通常只能在教务系统中查看，不方便和日常日历、提醒事项放在一起管理。 这个工具把个人课表解析成标准 iCalendar（.ics）， 你可以导出文件，导入 Apple Calendar、Google Calendar、Outlook 等日历应用， 也可以把它发布成一个订阅 URL，让日历客户端定期回源取最新。

    与直接套用循环规则的做法不同，它会显式解析课程名称、教师、地点、星期、节次与周次， 把教学周换算成具体日期，并按当天的冬 / 夏季作息换算节次对应的钟点 —— 因此学期中途切换作息也不会算错时间。每一次实际上课生成一个独立事件， 事件标识稳定，所以在会回源的客户端上，改课表现为原地更新，不会攒出一堆重复条目。 停课和考试改期也会以已取消的状态下发，客户端照不照做，取决于它自己。

    产物除了课程，还可以带上考试安排（默认包含，可以关掉），以及学校发布过的校历全天事件， 例如起课、报到注册、考试周、寒暑假、放假调休（这一项默认不带）。 订阅通路上各家客户端的脾气差别不小：安卓侧系统日历的订阅入口参差， 使用说明统一推荐走 ICSx⁵，逐家的回源周期与撤销行为也在里面列了矩阵。

    使用前需要自行配置官方校历与作息表，并具备 Python 3.11+ 环境； 登录由你在浏览器中亲自完成，工具不读取、不记录、不上传任何凭据。 选择发布成订阅 URL 时，产物里有什么就是公开什么：带上考试时， 考试名、时间、考场和座位号也在其中（考试项可以单独关掉）。 当前版本 v0.9.0（2026-10-16）。

  • 思源学堂工具

    可用

    下载思源学堂 2.0 里当前账号有权访问的课件、作业与课程回放，并按章节归类整理到本地。

    • 课程资源
    • 课程回放
    • 断点续传
    • 开源
    项目介绍

    思源学堂的部分课程附件由网页前端动态加载，直接保存网页并不容易完整保存课件、 作业与录像。这个工具把当前账号有权访问的课程资源统一抓取到本地， 按课件、作业、录像等类型与章节归类，清单、下载、整理一条龙。

    抓取过程带断点续传、失败重试、文件大小与 SHA-256 校验，也支持只补新增的增量更新， 以及先看清单不动文件的预览模式。之所以要专门做，是因为附件散在三类来源里 （活动附件数组、活动正文内嵌、直播回放地址），只读其中一类会漏 —— 课件 PDF 几乎都在正文内嵌那一类里，只看附件数组会误判成「这门课没有课件」。

    三种用法可选：装成 Skill 交给编码助手，说一句「下载这门课的课件」就能跑完整个流程； 直接用配套的 Prompt；或者按命令行自己跑 scripts/ 里的脚本。 需要 Python 3.8+，其中只有登录环节依赖浏览器自动化。

    它只访问当前登录账号本身就有权访问的课程与资源，不绕过统一身份认证， 也不改变服务器对课程资源的权限判断；整个流程用的是你本人登录后得到的会话状态。 主要用于个人学习中的备份、归档与离线整理，请遵守学校规定、 课程资源的版权要求与教学平台的正常使用规则。 当前版本 v1.6.0（2026-10-08），未发布到 PyPI，从仓库或 Release 附件获取。

关于

XJTU Student Tools 是若干独立学生工具的统一入口。

  • 独立维护每个工具单独开发，互不依赖。
  • 独立发布各自拥有仓库与 release，可以单独升级或停止维护。
  • 独立版本管理版本号互不影响，不使用统一的 monorepo 版本。
  • 认证信息不经手门户本站不接收、不存储、不处理账号密码、Cookie、Token 或统一身份认证凭据。

本站只是一层导航与文档入口——它不复制子项目的源码，也不代替子项目的说明文档。 使用具体工具时，请以对应仓库的文档和安全须知为准。

安全与隐私

  • 本站本身不要求输入西安交通大学账号或密码。
  • 不要向任何公开 Issue、日志、截图或讨论中提交 Cookie、Token、Session 等认证信息。
  • 使用各子项目时，请先阅读对应项目的安全说明与使用范围。
  • 所有工具都应尽量在用户本地处理认证信息与数据，凭证不应上传到第三方服务。
